# Functional Storage

Unofficial NeoForge + Fabric port of [Functional Storage](https://github.com/Buuz135/FunctionalStorage) (drawers, controllers, upgrades). Mod id stays `functionalstorage`. Titanium Lite is bundled in the jar, so nothing extra needs to be installed.

[Functional Storage](https://github.com/Buuz135/FunctionalStorage) 的非官方 NeoForge + Fabric 移植（抽屉、控制器、升级）。mod id 保持 `functionalstorage`；钛 Lite 已内置在 jar 内，无需另外安装。

## Branches

| Branch | Minecraft | Loaders |
|---|---|---|
| `26.3` | 26.3 | NeoForge, Fabric |
| `26.1-26.2` | 26.1 – 26.2 | NeoForge, Fabric |

Each branch is a self-contained Gradle project; the branch name is also the jar's Minecraft label.
