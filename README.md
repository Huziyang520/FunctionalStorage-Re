# Functional Storage

Unofficial NeoForge + Fabric port of [Functional Storage](https://github.com/Buuz135/FunctionalStorage) — drawers, controllers and upgrades unchanged. Mod id stays `functionalstorage`.

[Functional Storage](https://github.com/Buuz135/FunctionalStorage) 的非官方 NeoForge + Fabric 移植，抽屉、控制器与升级内容保持不变。mod id 保持 `functionalstorage`。

## Branches

| Branch | Minecraft | Loaders | Mod version |
|---|---|---|---|
| `26.3` | 26.3 | NeoForge, Fabric | `1.26.0` |
| `26.1-26.2` | 26.1 – 26.2 | NeoForge, Fabric | `1.26.0` |

Each branch is a self-contained Gradle project; the branch name is also the jar's Minecraft label.

Titanium Lite is bundled inside the jar (jar-in-jar): do not install a separate Titanium jar next to it.
